# Auphelie support

Auphelie plays your own audiobooks from local folders or a compatible Audiobookshelf server. Audiobooks and server hosting are not included.

## Contact

Email Michael Kopt at [michaelkopt.apps@outlook.cz](mailto:michaelkopt.apps@outlook.cz) for help or to report a problem. Include your device model, operating system, Auphelie version/build, whether the problem concerns a local or server library, the steps that led to it and what you expected. No response-time commitment is made.

Avoid sending passwords, access tokens, custom authentication headers, private server addresses or copyrighted audio. Redact personal information and book/server details from screenshots and logs before sending. Describe a file's format and behavior first; send sample files only when you have permission and after agreeing a safe handoff.

## Add and play a local library

Add a library and choose a folder containing your audiobooks. Open the library, browse to a playable file and select it. Use play/pause, previous/next, seeking and playback speed controls. Auphelie recognizes MP3, MP4, M4A and M4B files; successful playback depends on the device decoder and the individual file. If a folder becomes unavailable, check its storage location and permissions, then refresh or select it again. Keep a separate backup of your books.

## Connect to Audiobookshelf

Use an HTTPS server you trust and an account authorized to access its libraries. Enter the server URL and login details; add custom headers only if your server administrator requires them. Test the connection and select the libraries offered to your account. If login fails, check the URL, account access, server availability and network connectivity with the server operator. Do not post authentication details in a public issue.

## Playback and progress problems

If a book will not play, try another supported file and note whether the issue follows one file or an entire library. Check connectivity for server content. For missing progress, identify the book and source, whether playback was local or server-backed, and whether the server was reachable. Do not assume that every book has been downloaded or that remote progress can sync while disconnected. Background and system-control behavior can vary by platform and needs device-specific investigation.

## Privacy and removing a connection

Read the [privacy policy](privacy.md) for local storage, server requests and support email handling. Disconnecting removes local server connection secrets and sources; it does not delete the remote account or its records. Contact the server operator for remote account/data deletion. Email the publisher for questions or deletion requests concerning support correspondence. No universal deletion or retention guarantee is made.

## Content and accessibility

You and your library operator supply the audiobooks and must have permission to use them. The app does not certify the suitability of every book or filter mature content. To report an accessibility issue, describe the screen, device, assistive technology and the action that is difficult; omit private content.
